# 项目介绍与代码分析

FOC Studio 是基于 ODrive v0.5.1/ODrive V3.6 的单轴 FOC 工程。目标电机为 3505-KV650，M0 默认参数为：10 pole pairs、0.1 ohm、42.3 uH、约 0.012723 Nm/A、2 A bring-up current limit、0.2 Nm torque limit、500 rad/s current-control bandwidth。默认 SPI 编码器为 16384 CPR；ABZ 工作流使用 4000 CPR。

实际烧录目录是 `odrive-baseline/Firmware`。`firmware/` 只包含可在 host 上测试的 portable core 和 vendor snapshot，不能替代实际固件。详细边界见 [SOURCE_OF_TRUTH.md](SOURCE_OF_TRUTH.md)。

主机应用 `host/foc-studio` 通过 USB CDC ASCII 协议发送模式、位置、速度、力矩、校准、急停和遥测命令。固件解析位于 `communication/ascii_protocol.cpp`。`Axis` 管理状态机与控制循环，`Encoder` 提供 ABZ/SPI 估计，`Controller` 产生 torque setpoint，`Motor` 处理 FOC 电流环和 PWM。

ABZ 低速相关改动明确限制在速度/位置级联外环：rolling window、PLL blend、filter、gain schedule、bounded integral 和 `LowSpeedCompensator`。它们不应触及 torque `c` 路径、Motor current PI、Clarke/Park、SVPWM、commutation 或 Sensorless。完整路径和已知边界见 [CONTROL_ARCHITECTURE.md](CONTROL_ARCHITECTURE.md)。

本审查阶段不声称解决实机低速问题。代码可证明的是状态、参数和安全路径；历史实测结论因 Git 元数据缺失无法重新核验；0.2–2 turn/s 的实际稳定性必须按 [HIL_TEST_PLAN.md](HIL_TEST_PLAN.md) 采集数据后判断。
