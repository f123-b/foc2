DEVICE CONFIG
参数配置

          
电机与闭环3505-KV650 · M0

          

            
          

          
写入保护：必须先读取设备参数，再加载或修改参数。电机方向、极对数和 CPR 不参与批量写入。扭矩与位置使用稳定的基础控制路径；速度反馈低通只在速度模式临时启用。

          
制动电阻与回馈

          

            
          

          
只写入可编辑字段；相电阻、相电感和预校准标志不会被批量覆盖。
未接制动电阻：保持 0 Ω 并关闭过压斜坡。
目标板上将电阻跨接在 DC+ 与 AUX 之间（无极性），绝不能接在 DC+ 与 DC- 之间。5 Ω / 50 W 更适合本项目；2 Ω / 50 W 只能承受短脉冲。
AS5047P SPI3：CS 接 GPIO4 / PA3，SCK 接 PC10，MISO 接 PC11，MOSI 接 PC12；使用 3.3 V 逻辑并与控制器共地。
